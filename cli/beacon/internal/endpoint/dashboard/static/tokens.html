Import validation rules

  • File size and row limits; version field must be version 1
  • Record IDs are unique; no duplicates
  • Four token counts are explicit non-negative integers
  • Status field must use the allowed enum

A successful import replaces the previous snapshot as a whole (there is no history). The import only provides statistics; it does not add command or file audit records and does not enable live collection.
